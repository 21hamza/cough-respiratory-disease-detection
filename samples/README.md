# Sample recordings

Eight `cough-heavy.wav` recordings from the **held-out test set** of the fixed split, so the trained models never saw
them. `labels.csv` gives each recording's true self-reported status. Two are deliberate failure cases:
`covid_4_missed` (all four models say healthy) and `healthy_4_false_alarm` (most models say COVID).

Source: Coswara database, LEAP Lab, Indian Institute of Science, Bangalore
(https://github.com/iiscleap/Coswara-Data), licensed under CC BY 4.0. The files are unmodified copies.
